隐空间通信的坍塌危机：
为什么VLM Agent之间其实"听不懂"彼此

Vision Wormhole UVC的维度坍塌诊断与自监督修复

组会汇报 · 2026年6月

背景：Vision Wormhole — 让不同VLM Agent通过"意识"交流

  • 不同厂商的VLM（Qwen、LLaVA、Gemma...）内部表示千差万别，无法直接通信
  • Vision Wormhole提出UVC（Universal Visual Codec）：把hidden state压缩到共享连续隐空间
  • Agent之间发送"思想向量"——一个512维浮点数数组——通过视觉接口注入接收方
  • 训练目标：Teacher-Student蒸馏
  • Teacher = Text Pathway输出（自然语言天然跨模型）
  • Student = Visual Pathway / Codec（学习隐空间）
  • Loss = MSE(student_h, teacher_h) + KL(student_logits, teacher_logits) + 统计对齐
核心问题：这个512维的"思想向量"，真的承载了丰富信息吗？

核心发现：512维通道，只有2根水管在流水

对UVC输出的512维latent space做SVD分析，发现严重维度坍塌。

关键发现

  • 512维隐空间实际只使用2-3个有效维度，其余509维是复制粘贴
  • Token Cosine Similarity = 0.999：无论输入什么，输出向量几乎完全相同
  • 训练越久越差：step 150 Eff Rank 3.61 → step 300 降到3.01
  • 这不是欠拟合——是退化（collapse）

为什么坍塌？Teacher-Student蒸馏的退化捷径

1. 退化捷径

  • Teacher本身通过离散文本输出，其latent多样性有限
  • Student发现一个简单解：对所有输入输出"平均向量"就能让MSE很低
  • 这比学习真正的信息编码容易得多——梯度自然流向退化解

2. 梯度方向集中化

  • Loss landscape在大部分方向上曲率为零
  • 梯度只更新2-3个主方向，其他维度从未被有效训练
  • 形成自反馈循环：不用的维度 → 梯度为零 → 继续不用 → Dead Dimensions

3. VICReg正则化为何不够

  • 方差+协方差正则只能"推远"已存在的向量
  • 无法重建已完全丢失的维度
  • Eff Rank从2→5，远不够（健康值 > 50）
  • 正则化是创可贴，不是手术
结论：Teacher-Student蒸馏在异构VLM架构上是结构性失败——调参和加正则解决不了。需要换训练范式。

修复方案：I-JEPA自监督替代蒸馏

核心思路

不做"模仿老师"，做"预测自己的另一面"。同一输入加不同噪声，从A的表示预测B的表示。

Stage 1：I-JEPA Encoder预训练

  • anchor + noise_a → encoder → U_a → predictor → 预测U_b
  • anchor + noise_b → encoder → U_b (stop-gradient, 做目标)
  • Loss = MSE(pred, target) + 反坍塌正则 (方差 + 协方差)
  • 预测任务天然防止坍塌：不同输入必须产生不同输出
  • 结果：Eff Rank从2.32 → 110.99（48倍提升）
  • Token CosSim从0.999 → 0.862（token之间终于有差异了）

Stage 2：冻结Encoder，只训练Decoder

  • Encoder已学会丰富表示→冻结，不再变化
  • Decoder从头学习"把丰富表示翻译成有效VLM注入"
  • 两阶段解耦：表示学习（防坍塌）与通信翻译（蒸馏）分开

关键洞察

教师-学生蒸馏的问题不是"有蒸馏"，是"用蒸馏做表示学习"。把表示学习外包给I-JEPA，蒸馏只做翻译，双方各司其职。
